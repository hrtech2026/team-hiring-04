# Прототип скрининга резюме

Учебный прототип использует облачный **GigaChat API**, по умолчанию модель
`GigaChat-2`. Целевая архитектура проекта предусматривает внутреннюю модель.

## Запуск

На Windows запустите `start-demo.cmd` двойным щелчком или выполните
`node --use-system-ca server.mjs` в папке `prototype` (Node.js 24+).
Пока окно сервера открыто, сайт доступен по адресу [127.0.0.1:8787](http://127.0.0.1:8787).
Локальный сервер читает `GIGACHAT_AUTH_KEY` из окружения или файла
`.gigachat.local`, исключённого из Git. По умолчанию используется scope
`GIGACHAT_API_PERS`. Если система ещё не доверяет сертификату Минцифры,
сохраните PEM из [инструкции GigaChat](https://developers.sber.ru/docs/ru/gigachat/certificates)
рядом с сервером под именем `.gigachat-ca.pem`.

1. Нажмите «Загрузить пример», затем «Перейти к профилям».
2. Нажмите «Подготовить профили в GigaChat» и подтвердите отправку синтетических данных.
3. Проверьте критерии и фрагменты резюме, затем нажмите «Утвердить и сопоставить».
4. Проверьте отчёт и укажите решение рекрутера с основанием.

Сайт принимает TXT/MD и вставленный текст. Для автономного просмотра можно
открыть `index.html` напрямую и сформировать отчёт по словам.

## Синтетические примеры

| Уровень | Файлы | Что проверить |
|---|---|---|
| Junior | [Вакансия](examples/junior-vacancy.txt) и [резюме](examples/junior-resume.txt) | Все обязательные критерии подтверждаются. Кандидат прямо пишет, что Docker Compose не использовал. |
| Middle | [Вакансия](examples/middle-vacancy.txt) и [резюме](examples/middle-resume.txt) | Опыт с Celery подтверждён частично: задачи есть, повторных попыток нет. Про Prometheus и Grafana сведений нет. |

Можно загрузить оба резюме к одной вакансии и сравнить результаты без смены критериев.

## Системные промты

| Обращение | Вход | Выход |
|---|---|---|
| 1А · Вакансия | Текст синтетической вакансии | Черновик критериев, цитаты и вопросы |
| 1Б · Резюме | Синтетическое резюме без реальных персональных данных | Структурированные факты и дословные фрагменты |
| 2 · Сопоставление | Подтверждённые критерии и проверенные фрагменты одного резюме | Статусы, цитаты, пробелы и вопросы рекрутеру |

Запросы выполняются последовательно, отдельно для каждого резюме.
[Промты подготовки](preparation-system-prompts.js) и
[промт сопоставления](match-system-prompt.js) доступны на шаге проверки профилей.
Сервер передаёт GigaChat отдельную JSON-схему для каждого обращения.
Перед показом отчёта сайт проверяет состав строк и статусы, а цитаты
подставляет из проверенных фрагментов по их номерам.
Замечание по обезличиванию останавливает
обработку до ручной проверки. Решение принимает рекрутер.
