Вакансия: Junior Python Backend Developer

Команда разрабатывает сервис учёта заявок. Задачи: добавлять небольшие эндпоинты, писать тесты и исправлять ошибки по результатам ревью.

Обязательные требования
— Базовое владение Python 3. Допустимы учебные и личные проекты.
— Разработка REST API на FastAPI или Flask.
— Умение писать SQL-запросы с JOIN и GROUP BY.
— Работа с Git: ветки и pull request.

Желательные требования
— Написание тестов с pytest.
— Запуск приложения с Docker Compose.

Коммерческий стаж для этой позиции не требуется.
