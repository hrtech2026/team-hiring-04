Вакансия: Middle Python Backend Developer

Команда развивает сервис обработки заказов. Задачи: проектировать API, ускорять работу с базой данных и поддерживать фоновые процессы.

Обязательные требования
— Не менее 3 лет коммерческой разработки на Python.
— Проектирование REST API на FastAPI или Django REST Framework.
— Оптимизация запросов в PostgreSQL с использованием EXPLAIN ANALYZE и индексов.
— Разработка фоновых задач на Celery с повторными попытками при временных сбоях.

Желательные требования
— Настройка метрик в Prometheus и дашбордов в Grafana.
— Настройка пайплайна сборки и тестирования в GitLab CI.
