Синтетическое обезличенное резюме J-01
Желаемая роль: Junior Python Backend Developer

Проект «Учёт заявок», учебная команда, 4 месяца.
На Python 3 и FastAPI реализовал эндпоинты создания заявки, получения списка и смены статуса.
В PostgreSQL писал запросы с JOIN и GROUP BY для отчёта по открытым заявкам.
В Git создавал отдельную ветку под каждую задачу и открывал pull request на ревью.
Написал 12 тестов с pytest для эндпоинтов и проверок входных данных.
Приложение запускал локально, Docker Compose в проектах не использовал.

Образование: завершил учебный курс по разработке веб-сервисов на Python.
