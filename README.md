## Как работаем

Работы распределены по ролям и документам из таблицы выше. Перед сдачей сверяем связанные документы, проверяем ссылки и запускаем `validate-docs.yml`. Изменения в репозитории оформляем через Pull Request.

## Сдача этапа

1. Все документы этапа находятся в `main`.
2. Проверка `validate-docs.yml` завершилась успешно.
3. `data/meta.yml` содержит актуальные этап и концепт; состав и роли обновляются через заявку «Изменение состава».
4. Карточка команды переведена в соответствующую колонку доски.
5. В Pull Request оставлен комментарий `Сдаю этап N`.
